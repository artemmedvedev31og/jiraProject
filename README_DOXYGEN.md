# Документация Doxygen для Genius Music Bot

## Состав комплекта

- `Doxyfile` — конфигурация Doxygen для Java/Maven-проекта.
- `mainpage.md` — главная страница документации с описанием приложения и задач SCRUM-8, SCRUM-9, SCRUM-10, SCRUM-15 и SCRUM-16.
- `src/main/java/*.java` — версии выбранных исходных файлов с добавленными комментариями JavaDoc/Doxygen.

## Как добавить в существующий проект

1. Сделайте коммит или резервную копию текущих исходников.
2. Распакуйте содержимое архива в корень проекта рядом с `pom.xml` и `README.md`.
3. Если Windows спросит о совпадающих файлах, согласитесь на замену только для файлов из `src/main/java`, входящих в этот комплект. В них добавлены комментарии документации; логика методов сохранена по доступной версии репозитория на момент подготовки комплекта.
4. Проверьте различия исходников через Git (`git diff`) до коммита.
5. Откройте `Doxyfile` в Doxywizard. Поле **Working directory** должно указывать на корень проекта, где расположены `pom.xml`, `Doxyfile`, `mainpage.md` и `src`.
6. Нажмите **Run doxygen**.
7. Откройте `docs/html/index.html` в браузере.

## Генерация из терминала

В корне проекта:

```powershell
doxygen Doxyfile
```

Если команда `doxygen` не распознана, используйте Doxywizard либо добавьте каталог с `doxygen.exe` в `PATH`.

## Какие задачи документируются

- **SCRUM-8** — ввод имени исполнителя и запуск поиска (`MainMenu`).
- **SCRUM-9** — HTTP-клиент Genius API (`GeniusClient`).
- **SCRUM-10** — модели и разбор JSON-ответа (`GeniusResponse`, `Response`, `Hits`, `Result`).
- **SCRUM-15** — ошибки сетевого запроса и тайм-аут установления соединения (`GeniusClient`).
- **SCRUM-16** — ограничение числа результатов и получение ссылок на треки (`GeniusClient`).

Комплект содержит выбранные классы; он не предназначен для замены всего проекта. Остальные исходники останутся на месте и также попадут в документацию благодаря `RECURSIVE = YES`.
